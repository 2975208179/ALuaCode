# ALuaCode
ALuaX Android Lua开发工具

安卓端Lua开发工具，支持Lua代码编写、运行，打包生成APK。

## ✨ 功能特性
- Lua代码编辑器编写代码
- 代码运行调试
- 直接打包生成APK
- 安卓端独立开发环境，无需电脑
